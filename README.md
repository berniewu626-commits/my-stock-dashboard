# 台股戰情室

保留原有 28 族群、強勢股雷達、熱力圖與族群 K 線，新增獨立自選股觀察區。

## 執行

建議 Python 3.12：

```sh
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

## 自選股

- 輸入一個或多個代號，按「加入／匯入自選股」。支援逗號、空白、換行分隔；大小寫自動正規化並去重，最多 30 檔。
- 可填完整 Yahoo 代號，例如 `2330.TW`、`5347.TWO`、`0050.TW`；僅填數字時，依市場選單補 `.TW`（上市）或 `.TWO`（上櫃），不猜測市場。格式正確不代表股票存在；無資料時請確認後綴。
- 透過多選欄位與「刪除所選股票」管理清單。刪除只影響自選區，不改變 28 族群資料。
- **預設清單為空，只存在目前 Streamlit session**，重整頁面、斷線或服務重啟可能清空；沒有跨裝置／帳號同步。按「下載自選清單」備份純文字，下次將內容貼回輸入框即可合併匯入。
- 清單不寫入儲存庫、共用伺服器檔案或網址。只有公開行情按「代號＋查詢日期」快取 5 分鐘，使用者之間不共用自選清單。查詢代號仍會傳給 Yahoo 行情來源。

## 行情解讀

自選區沿用側欄查詢日期，每檔分別顯示最近可用資料交易日、前一筆有效收盤價日期、最新股價、漲跌幅和成交量（**股**）。查詢歷史日期時，「最新」是截至該查詢日，不是今天報價。表格與所選股票 K 線來自同一份近 180 天日線資料，排除未來資料、無效價格及無效 K 線。

漲跌幅以未還原收盤價比較，除權息可能造成價格跳空；若資料中間有缺漏或暫停交易，這是兩個實際資料日間的區間報酬，不保證是相鄰交易日報酬。只有一筆報價時仍顯示股價，漲跌幅留空。缺漏成交量不當成零；缺漏 OHLC 不隱藏可用報價，K 線會提示略過資料。

休市、資料延遲及盤中提示沿用 main 的 `market_dates.py`。不以自選股日期覆寫族群日期；本次未改動原有族群的下載／日期政策。行情可能延遲或修訂，不是即時成交報價。單股失敗會提示且保留其他股票，可按「更新自選股行情」重試。

## 測試

```sh
python -m unittest discover -s tests -v
```

GitHub Actions 對 PR 與 main push 執行測試。包含原有日期測試、代號／行情邏輯與 Streamlit AppTest；自動測試使用模擬行情，不依賴 Yahoo 網路。測試中的市場代號僅為驗證案例，不是預設持股。
